# 🌍 Country Information Application

This project is a simple web application that uses the **REST Countries API** to provide detailed information about countries. By entering a country name, users can see its flag, population, official language, capital, and currency. In addition, the neighboring countries are also listed.

---

## 🚀 Technologies Used

- **HTML5** – Page structure  
- **CSS3 / Bootstrap 5** – Responsive design and modern UI  
- **JavaScript (Fetch API)** – API requests and dynamic content handling  

---

## 📸 Features

- Search by entering a country name  
- Error message displayed for invalid or incorrect input  
- Country details displayed in a modern card layout  
- Neighboring countries listed with flags and names  
- Mobile-friendly and responsive design  

---

## 🌐 API Source

This application uses data from [REST Countries API](https://restcountries.com/).

# 🌍 Ülke Bilgileri Uygulaması

Bu proje, **REST Countries API** kullanarak ülkeler hakkında detaylı bilgiler sunan bir web uygulamasıdır. Kullanıcı, bir ülke adı girerek ülkenin bayrağını, nüfusunu, resmi dilini, başkentini ve para birimini öğrenebilir. Ayrıca seçilen ülkenin komşu ülkeleri de listelenir.

---

## 🚀 Kullanılan Teknolojiler

- **HTML5** – Sayfa yapısı  
- **CSS3 / Bootstrap 5** – Responsive tasarım ve modern arayüz  
- **JavaScript (Fetch API)** – API istekleri ve dinamik içerik yönetimi  

---

## 📸 Özellikler

- Ülke adı girilerek arama yapılabilir  
- Yanlış veya geçersiz girişlerde hata mesajı gösterilir  
- Ülke bilgileri modern bir kart yapısında görüntülenir  
- Komşu ülkeler bayrak ve isimleriyle kart halinde listelenir  
- Mobil uyumlu ve duyarlı (responsive) tasarıma sahiptir  

---

## 🌐 API Kaynağı

Bu uygulama [REST Countries API](https://restcountries.com/) verilerini kullanmaktadır.
